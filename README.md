**Project Paragraph - Expiration date tracker**
The expiration date tracker is an application that keeps track of food/pantry and cosmetic product's expiration dates, alert the user when a the expiration date has passed, and can generate a list of products that are going to expire soon (1 week, 1 month, etc.). Anyone may use it based on their needs but it could be extra useful for professionals like cooks, restaurant owners, makeup artists, or even just an average person who wants to keep track of their household items.
